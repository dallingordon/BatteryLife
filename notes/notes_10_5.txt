--- Speed-up discussion ---
1. Single pass per cell (causal model: the hidden state at each cycle boundary IS the prefix answer) -> ~K x fewer steps
   for full history; also could make the <=100 runs ~50x cheaper (one pass instead of prefixes 1..100). Not yet done for <=100.
2. Run S4D through Mamba's fused selective scan (constant dt/B/C) instead of the FFT kernel -> linear memory, Mamba speed.
3. Hardware: gpu_c=8.0 (A100/L40S/H100) ~2-3x over V100 for FFT; costs queue time.
4. Downsampling 300 -> 100 points/cycle is an option; do NOT skip late cycles (breaks fixed time step = the LTI question).

--- Long-tail pretrain -> finetune (Option A), Li-ion only ---
Pretrain: each epoch every Li-ion train cell gets K (=1) random lengths n ~ U[100, L]. One pass: R token before every
  cycle (guidance loss on each, EOL target), F after cycle n. Val/early stopping = usual F on prefixes <= 100.
Finetune: normal Li-ion readout + R_FIRST run (<= 100), init from pretrained weights, fresh optimizer.
Option B (100-cycle late-life windows, remaining-life target, head reset) NOT built yet.

Hold: S4ft sits in hqw, released automatically when S4tail leaves the queue (finished OR crashed).
  Eqw on S4tail keeps it held -> qdel S4tail. -hold_jid by NAME waits on every job named S4tail; use the job id if
  another S4tail gets submitted. qalter -hold_jid <id> <S4ft id> changes it in place.

Failure modes to check:
  - test_s4d.qlog FAIL on scan checks / S4tail dies on step 1 -> fork's CUDA scan rejects complex A -> write S4D-Real fallback.
  - OUT OF MEMORY at 3842 cycles in the --long test, or S4tail dying mid-epoch -> resubmit with FULL_MAX_CYCLES=2000.
  - S4ft runs even if S4tail crashed: "INIT_CKPT ... does not exist" if no checkpoint; if a checkpoint was saved before the
    crash it finetunes from a PARTIAL pretrain -> read S4_tail_pretrain.qlog before trusting S4ft.
  - K=1 epochs are short (one sample per Li-ion train cell, /32 optimizer steps; count is in the epoch summary line), val may cost more than training; FULL_K=4 is the alternative.
