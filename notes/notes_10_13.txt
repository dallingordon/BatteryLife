--- Idea: hierarchical "simulator" (later) ---
Inner SSM over points of one cycle: input = controls (protocol current / phase / dt), output = voltage response,
  initial state from the outer model. Run in simulation mode (no observed V as input) -> parallel, no point-level
  teacher forcing. For diagonal LTI S4D the initial-state response is closed form: y_t = 2 Re(sum_n C_n exp(A_n tau_t) x0_n).
Outer SSM over cycles: input z_k (encoded observed cycle) + cycle-level controls, h_k -> inner init for k+1,
  capacity head, z_{k+1} prediction. Roll out from cycle 100 until capacity < 0.8 -> EOL.
Notes:
  - Input-free LTI rollout (h_{k+1} = A h_k) can only decay -> no knee. Need closed loop through nonlinearity
    (feed predicted z back). LTI shared dynamics + nonlinear feedback.
  - Teacher forcing: TF over all cycles (parallel) + latent AR (predict z_{k+1}, feed back) + multi-step rollout loss
    from random k0 (mostly near 100), curriculum on horizon. Scheduled sampling = weaker fallback.
  - CV phase: voltage is controlled, current is the response; discharge ends at V cutoff -> the real input is the
    protocol, not the measured trace (measured trace length leaks capacity).
  - Check first: does "first cycle with discharge cap < 0.8 x nominal" in the cache reproduce the label JSONs?
  - Data now: 300 points resampled by RECORD INDEX (150 charge + 150 discharge), time_in_s dropped,
    V normalized by the cycle's own max V (hides resistance growth), I in C-rate, Q / nominal. Rests (|I| < 0.01C) dropped.
Decided: do explicit dt in the current S4D / Mamba setups FIRST (one-variable test on the 0.203 / 0.267 baselines).

--- Explicit dt plan ---
Cache: interpolate time_in_s at the resampled points, store dt as a 4th channel. Global unit (not per cycle/cell).
  Normalize tau = dt / c, c = one global constant (median within-segment dt over Li-ion train cells, from stats pass).
  Any constant c is absorbed by the learned log_dt; c only sets the init range / numerics. With tau == 1 the model
  reduces exactly to the current one (built-in control). Clip tau at a high percentile if the tail is extreme (stats pass).
  Same c for all chemistries later so rates stay comparable.
Rests: v1 leaves them out (boundary steps get typical dt). Thinking: a REST TOKEN at boundaries carrying the rest
  duration (decay by exp(A * tau_rest), input term kept normal size). Not decided.
S4D: scan backend only (FFT needs constant step). delta[b,e,t] = exp(log_dt[e]) * tau[b,t]. Drop exact-ZOH B fold,
  use kernel's delta*B*u (same as Mamba). Test vs exact variable-dt recurrence.
Mamba: "dumb down" dt to exactly the S4D form: delta = exp(log_dt[e]) * tau[b,t], NOT input dependent
  (B, C stay selective). Remove the dt_rank part of x_proj and dt_proj; delta_softplus=False, delta_bias=None.
  Unfused path. log_dt no weight decay (same tagging as S4D).
Open: dt for R / boundary tokens (tau=0 -> token reads state but does not write; tau=1 -> current behaviour).
  The causal depthwise conv (width 4) stays index-based, not time-aware.
Experiments (Li-ion readout + R_FIRST, 3 seeds each): S4D + log-dt input channel only | S4D-time | S4D-time + input |
  Mamba-time. Baselines exist (S4D 0.203, Mamba 0.267 + seed 2024 to run).
