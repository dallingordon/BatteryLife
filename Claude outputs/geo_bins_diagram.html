Geometric ("15%-band") bins along the identity line

Each bin is sized so that classifying it correctly is (approximately) the same as landing within the paper's own ±15% accuracy tolerance. Bin width is constant in relative terms, so it grows geometrically in absolute cycles as the true value increases — the dots are the only 28 values the model can ever emit. The only vertical lines in each chart are the 28 bin edges; there's exactly one between each pair of adjacent dots.
