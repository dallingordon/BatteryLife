# Version 12 of BatteryLife_Processed_Dataset update details

Here are the update details of Version 12 compared with Version 11:

1. The complete version of the XJTU dataset is provided in version 12, and can be downloaded from [Huggingface]([Battery-Life/BatteryLife_Processed · Datasets at Hugging Face](https://huggingface.co/datasets/Battery-Life/BatteryLife_Processed)) and [Zenodo](https://zenodo.org/records/21149533).
2. In version 12, we release a new dataset Farasis, which consists of 123 industrial-grade large-format lithium-ion pouch cells. The processed dataset and the details of the dataset can be found at [BatteryLife_Farasis]([Battery-Life/BatteryLife_Farasis · Datasets at Hugging Face](https://huggingface.co/datasets/Battery-Life/BatteryLife_Farasis)).



# Announcement

Starting from Version 12, all newly added datasets from the BatteryLife project will be released exclusively on the Hugging Face platform. Each new dataset will be made available as an individual dataset under the BatteryLife project space.

We sincerely invite researchers in battery health management to continue following and supporting the BatteryLife.
